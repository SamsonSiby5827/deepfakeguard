Is this face real or a deepfake?

Upload a photo with a face. The model finds the face, crops it and estimates whether it is real or a face-swap deepfake.

Research and non-commercial use only. A probability, not proof.

Your result will appear here. Images are processed in memory and not stored.

How it works

  1. OpenCV finds the largest face and crops it with a small margin.
  2. An EfficientNetB0 model, trained on the Celeb-DF dataset, scores the 224 × 224 face crop.
  3. The app warns you when the face is missing, tiny or blurry, because the result is then less reliable.

Held-out accuracy 80% (fake recall 0.78) on 2,416 test images. Trained on face-swap deepfakes only, so it is not designed for fully AI-generated images. Developers: see the API documentation.
