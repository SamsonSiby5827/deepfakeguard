Deepfake Detection for Trusted Media Analysis
This prototype combines AI-based facial analysis and blockchain-based file verification to detect manipulated image and video content, verify registered media hashes, and extend the analysis pipeline to uploaded videos through sampled frame inference.
  • ✔Uses the trained V2 face-focused deepfake model for image and video frame analysis.
  • ✔Supports single-image, multi-image, single-video, and multi-video workflows.
  • ✔Displays blockchain verification for both images and videos.
Built with Flask, TensorFlow, OpenCV, SHA-256 hashing, and local blockchain verification.
